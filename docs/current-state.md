# Current development scope

The current candidate is a records-first workspace with an included launch
readiness template and optional manual repair application. TanStack Start owns
React documents and generated functions; Hono dispatches explicit HTTP families
before Start in the single emitted Worker. Applied core migration history remains
intact; additive Base authentication migrations are separate.

New installations use pinned Base operator-auth, SendGrid or Resend mail, and
Base deploy-kit. [Installation](installation.md) describes preparation, resource
custody, bootstrap and received-link confirmation. Provider configuration and
current authority remain required; ordinary records work needs no AI provider.

The source contains records, schema, policy, evidence, execution and operation
mechanisms. Their presence is not proof of every planned journey. The records
foundation and wider acceptance requirements are in
[ACCEPTANCE.md](../ACCEPTANCE.md); [CONTRACT.md](../CONTRACT.md) preserves stable
product semantics. Default local verification and the separate Docker authoring
profile are documented in [README.md](../README.md). Exact-candidate local,
hosted, publication and full-product acceptance must be recorded independently.
