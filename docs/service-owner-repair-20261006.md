# Current campaign-owner service authority

Critical-risk service preparation and atomic admission require the campaign owner’s current active operator, principal, launch membership and existing risk read scope. A different requester cannot preserve a revoked owner’s eligibility. Retry, exact run restrictions and notification suppression retain their independent checks.

This is a bounded implementation description. Historical development receipts
are retained outside the public distribution and do not establish this candidate’s
acceptance. Run the affected repair, launch and foundation suites in the current
`pnpm verify` profile. The wider workflow requirements and release boundaries in
[ACCEPTANCE.md](../ACCEPTANCE.md) remain open; see
[installation](installation.md) and [HANDOVER.md](../HANDOVER.md).
