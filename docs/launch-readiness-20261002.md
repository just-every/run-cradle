# Bounded manual repair slice

The optional repair application contains report submission, current typed identity checks, private photo evidence, device-only offline drafts and original-key reconciliation. A reviewed active mandate and exact evidence versions can open linked repair/work-order/case records. Version and epoch-bound pause, takeover, manual resume and cancellation do not activate provider progression. Current eligible contractor selection and received multi-line quote capture preserve source custody and current authority. Unknown prior submissions reconcile with the original command key; source recovery requires explicit continuation before quote submission. No booking, contractor contact, approval, provider action or payment is accepted by this slice.

This is a bounded implementation description. Historical development receipts
are retained outside the public distribution and do not establish this candidate’s
acceptance. Run the affected repair, launch and foundation suites in the current
`pnpm verify` profile. The wider workflow requirements and release boundaries in
[ACCEPTANCE.md](../ACCEPTANCE.md) remain open; see
[installation](installation.md) and [HANDOVER.md](../HANDOVER.md).
